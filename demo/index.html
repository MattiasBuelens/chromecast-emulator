      How this page works

      In Chrome, the Cast SDK talks to Cast devices through the Presentation API. The emulator replaces that API, so casting opens your receiver page in a window instead. This page loads three scripts, in this order, and nothing else is special about it: 

      <script src="presentation-polyfill.js"></script>
<script src="cast-sender-emulator.js" data-receiver-url="/receiver/"></script>
<script src="https://www.gstatic.com/cv/js/sender/v1/cast_sender.js?loadCastFramework=1"></script>

      The player is Media Chrome with <castable-video>, which casts with the Cast SDK, just like on a real Chromecast. The receiver is the basic Cast receiver from Google's documentation, with the emulator's receiver scripts loaded before the receiver SDK.

      See the emulator's README to use it in your own app.
